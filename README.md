# 工程承認会議 報告書 半自動作成ツール

医事会計システム更新プロジェクトの「工程承認会議（プロジェクト報告会）」の報告書を、Excel 雛形（`01_PJ…_V1.14.xlsx`）に半自動で記入する Windows 用ツールです。

- 過去の報告書を取り込み、見出しごとに過去の記載例を**候補**として表示します。
- 候補を選んで手直しし、雛形に記入します。
- 完全オフラインで動作します。Excel がインストールされた PC で使います。

## 使い方

1. **［雛形を開く］**で雛形を選びます。
   - 項目欄・文章セクション・記入ガイド（吹き出し）を自動で判定し、`data\format.json` に保存します。
   - 雛形のコピーは `data\template.xlsx` に置きます。
2. **［過去報告書フォルダを取込］**でフォルダを選びます。
   - サブフォルダを含む .xlsx / .xlsm を読みます。`~$` で始まる一時ファイルは読みません。
   - 結果は `data\cases.json` に保存します。報告書を追加・修正したら［再取り込み］で読み直します。
3. 画面上部で**会議**（工程承認会議／報告会）、**工程**、**作成日**、**トピック**を入れます。
   - 例：トピック「自動精算機IF 未合意、WBS 45/50完了」
   - 前工程の顧客名や日付など、まとめて置き換えたい語句は**置換**（旧語句 → 新語句 ［+］）に登録します。③に追加する候補へ自動で適用されます（× で削除）。
4. **① 見出し一覧**で見出しを選びます。

   | 状態 | 意味 |
   |---|---|
   | ✔ | 記入済 |
   | ● | 候補あり |
   | 無印 | 未記入 |
   | 手入力 | 罫線で囲まれた表（ツールでは記入しません） |
   | 要確認 | 見出しが見つからない・重複している（下記） |

5. **② 候補**に、その見出しの過去の記載例が並びます。
   - 上部の黄色い枠は、雛形の吹き出しの**記入ガイド**です。
   - 候補はトピックとの類似度・同じ工程・出現回数・新しさの合計点の高い順です。点数は候補の上にマウスを置くと表示されます。
   - チェックして**［選択した候補を追加］**で③に入れます。
   - **［トピックを追加］**は、トピックをそのセクションの過去の書き方（行頭の「　・」など）に合わせて 1 行追加します。「、」で区切ると複数行になります。
6. **③ 記入内容**は自由に編集できます（［↑］［↓］［削除］［+行追加］）。
   - 候補から入れた**日付・数値を含むセル**は黄色で表示します。直すと黄色が消えます。
   - 「項目欄」を選ぶと、部署・氏名・顧客名・Prj名・作業内容・プロジェクト概要の入力欄になります。▼で過去の報告書の値を選べます。
7. **［Excelに反映（プレビュー）］**を押します。
   - 雛形を一時フォルダにコピーし、Excel を表示して記入します（原本は変更しません）。
   - 行が足りないセクションは、最終行の下に行を追加します。書式は上の行から引き継ぎ、図形も一緒に移動します。
   - 余った行は空欄にします（行は削除しません）。
   - ③が空のセクションは、雛形の記入例のまま残します。
   - プレビューの後、Excel 上で直接直してもかまいません。
8. **［名前を付けて保存］**で保存します。既定のファイル名は `{yyyyMMdd}_工程承認会議_{工程}.xlsx` です。

### 「要確認」の直し方

1. ① で「要確認」の行を選びます（理由が赤字で出ます）。
2. 雛形（`data\template.xlsx`）を Excel で開きます。開いていなければ、ボタンを押したときに開くか確認します。
3. 記入先のセルを選びます。セクションの場合は、記入範囲の先頭のセルを選びます。
4. **［選択中のセルを記入先にする］**を押します。結果は `data\format.json` に保存されます。

## 雛形の判定方法

| 対象 | 判定 |
|---|---|
| 対象シート | 名前に「工程承認会議」を含むシート（「版数管理」は対象外） |
| 項目欄 | ラベル（作成日・部署・氏名・顧客名・Prj名・作業内容・プロジェクト概要）の右のセル。結合セルなら左上。見つからなければ M1・M2・M3・C5・C7・C9・D14 を仮に使い「要確認」にします |
| タイトル | B1（上の 3 行で「工程承認会議」「報告会」「○○」を含むセル）。年月と「○○」を作成日・工程に置き換えます |
| 会議種別 | 「□工程承認会議 □プロジェクト報告会」のセル（既定 B12）。選んだほうを ■ にします |
| 文章セクション | B 列の「■」「○」「【」で始まるセルを見出しとし、次の見出しまでを記入範囲にします。最後のセクションは印刷範囲の最終行まで |
| 左右 1 組の欄 | 見出しと同じ行の右側に見出しがある欄（前回指摘事項｜対策結果、事前レビュー指摘事項｜対策内容、問題点｜対応策） |
| 手入力の表 | 算定トラブル防止施策・品質指標・課題件数・第三者チェック・○△× 評価と、罫線で囲まれた表 |
| 記入ガイド | P 列より右の吹き出し図形。図形の行位置から、その行より上で最も近い見出しに対応付けます |

## 過去報告書の取り込み

- 雛形と同じ方法で見出しを探し、セクションごとの記載行と項目欄の値を読みます。見出しを基準にするので、行が増減していても読めます。
- 各報告書の**工程**（タイトルの括弧内。末尾の「工程」は除く）、**作成日**、**顧客名**を保持します。
- 記載行は 1 行を 1 件の候補にします。
  - 「　　⇒」で始まる続きの行は、直前の行とまとめて 1 件にします。
  - 左右 1 組の欄で右だけに書かれた行も、直前の行の続きとみなします。
- 全報告書を通して同じ文面の候補は 1 件にまとめ、出現回数を数えます。

## 開発

```
main.py
app/
  template_parser.py  雛形の解析（Excel 不要）
  cases.py            過去報告書の取り込みと候補（Excel 不要）
  ranking.py          候補の並べ替え（Excel 不要）
  excel_com.py        Excel COM による記入・行の追加・保存
  ui.py               画面
tests/
  conftest.py         雛形の構造をまねた架空の xlsx を作る（図形・コメント・数式・結合・印刷範囲を含む）
  test_template_parser.py  test_cases.py  test_ranking.py
build.bat             pip install → pytest → PyInstaller
```

- **ビルド**：`build.bat` を実行すると `dist\ApprovalReport\ApprovalReport.exe` ができます（onedir 形式）。
  - Python 3.11 が必要です。`.venv` がなければ `py -3.11` か `uv` で作ります。
- **配布**：`dist\ApprovalReport` フォルダごとコピーします。
  - `data` フォルダは exe の隣に作られます。書き込めない場所では `%LOCALAPPDATA%\ApprovalReport\data` を使います。
- **テスト**：`.venv\Scripts\python.exe -m pytest -q`
  - テストデータは実在しない架空の名称で作ります。
- **候補の点数の重み**：`app/ranking.py` の `W_SIM`（類似度 1.0）、`W_PHASE`（同じ工程 0.3）、`W_COUNT`（出現回数 0.3）、`W_RECENT`（新しさ 0.2）で変えられます。

## 前提・制限

- 実際の雛形 V1.14 はこの開発環境になかったため、仕様のセル位置（B1・M1〜M3・C5・C7・C9・B12・D14）と見出しの構成をまねた架空の雛形で作成・確認しています。実際の雛形で判定がずれた箇所は「要確認」から指定してください。
- 項目欄・会議種別・タイトルは、画面上部と③の値で上書きします。項目欄の値が空なら雛形のまま残します。
- 行を追加すると、図形は行と一緒に移動します（「セルに合わせて移動しない」設定の図形も、追加の間だけ移動する設定にします）。印刷範囲がそのセクションで終わっていれば広げます。
